## Definition

The marketcap in USD is derived as the price of an asset in USD multiplied by the circulating supply of the same asset.

In addition to individual asset market caps, `marketcap_usd` is also available for the `TOTAL_MARKET` asset. This is the combined market capitalization of all tracked cryptocurrencies, including Bitcoin, Ethereum, stablecoins, and all other crypto assets (commonly referred to as TOTAL in the crypto industry).

For daily closing values of TOTAL, TOTAL2 (excluding BTC) and TOTAL3 (excluding BTC and ETH), use `daily_closing_marketcap_usd` with the `total_market`, `total_market_2` and `total_market_3` assets. See [Daily Aggregated Financial Metrics](/metrics/daily-aggregated-financial-metrics).

## SanAPI

### Marketcap USD

```graphql explorer
{
  getMetric(metric: "marketcap_usd") {
    timeseriesDataJson(
      slug: "ethereum"
      from: "2020-04-01T00:00:00Z"
      to: "2020-04-07T00:00:00Z"
      interval: "1d"
    )
  }
}
```
