## Definition

[Twitter/X.com Social Volume](/metrics/social-volume) can be broken down by account category.
Categorized Social Volume ships as a set of per-category metrics, each following the pattern `social_volume_twitter_<category>`.

Each metric counts social data text documents posted by accounts in a defined category that mention the given asset.
Document-counting mechanic (tweets/replies, "posted by" attribution) is carried over from how Social Volume counts documents.

See [Categorized Social Volume Details](/metrics/details/social-volume-categorized-details) for what accounts fall into each category, how assignment works, and how often it is reviewed.

Like Social Volume, data for these metrics may be supplemented with new data within a 12-hour period after it is first recorded.

These metrics are currently in beta status.

### Categorized Social Volume for an Asset

```graphql explorer
{
  getMetric(metric: "social_volume_twitter_btc_maxi") {
    timeseriesDataJson(
      selector: { slug: "bitcoin" }
      from: "2025-09-01T00:00:00Z"
      to: "2025-09-07T00:00:00Z"
      interval: "1d"
    )
  }
}
```
